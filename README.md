
# Control de dispositivos de red

Este proyecto consiste en una API para llevar un registro de los equipos que forman parte de una red.

Se utilizó FastAPI y Python para realizar las pruebas y registrar dispositivos.

La función principal que trabajé fue agregar equipos utilizando POST.

## Funcionamiento

- Registrar nuevos dispositivos.
- Guardar el nombre, tipo y dirección IP.
- Evitar que se registren equipos con el mismo nombre.
- Revisar que los datos estén completos.
